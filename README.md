## 主要项目

| 项目 | 简介 | 入口 |
| --- | --- | --- |
| **InvSync** | 基于 Redis + MySQL/MongoDB 的跨服数据同步插件，支持背包、经验、血量、成就及自定义数据同步 | [查看文档](https://halo.xbaimiao.com/archives/invsyncwen-dang) |
| **EasyPay** | 面向 Minecraft 服务端的支付插件，支持多种支付方式与累计充值 | [查看文档](https://halo.xbaimiao.com/archives/easypay) |
| **EasyLib** | 面向 Kotlin 的 Minecraft 插件开发基础库，简化数据库、命令、GUI、调度与配置开发 | [Maven 仓库](https://maven.xbaimiao.com/) |
| **FastFiller** | 高性能区域填充与批量操作工具 | [GitHub](https://github.com/xbaimiao/FastFiller) |
| **EasyRpc** | 面向 Minecraft 服务端生态的轻量 RPC 方案 | [GitHub](https://github.com/xbaimiao/EasyRpc) |
